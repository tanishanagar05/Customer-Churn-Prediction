# Customer Churn Prediction

A Machine Learning project that predicts whether a telecom customer is likely to leave the service.

## 🚀 Live Demo

**[Open Customer Churn Prediction App]([customer-churn-prediction-zjaqzrxigb9hmoejwxacyt](https://customer-churn-prediction-zjaqzrxigb9hmoejwxacyt.streamlit.app/)**

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Random Forest Classifier

## ✨ Features
- Customer details input
- Churn prediction
- Churn probability display
- Interactive web application

## ▶️ Run Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
